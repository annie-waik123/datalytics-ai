Data Layer

Database & Queue System

🍃

MongoDB + Motor

  • Flexible NoSQL document store
  • Motor = async driver (no blocking)
  • Stores users, datasets, payments, activity logs
  • No fixed schema — adapts to any dataset shape
⚡

Redis Cache

  • In-memory (RAM) — super fast
  • Caches EDA results — no repeated DB calls
  • Acts as message broker for Celery
  • Session & temporary data storage
🌿

Celery Workers

  • Runs heavy tasks in background
  • ML model training (minutes long)
  • Large EDA jobs on big files
  • User gets instant response — no freezing

Engineering

Challenges & Solutions

⚡

Large Dataset Performance

Solved

Problem: Pandas is slow on 500MB+ files. Solution: Used Dask for parallel chunk-based processing — 5x faster on large files.

🔄

ML Training Blocking the API

Solved

Problem: Training takes minutes — API would freeze. Solution: Celery + Redis background workers. User gets instant "started" response.

🌐

Frontend–Backend CORS Issues

Solved

Problem: Port 5000 ↔ Port 8000 = CORS errors everywhere. Solution: FastAPI CORSMiddleware + proxy rewrites in next.config.mjs.

🗂️

Different Dataset Shapes per User

Solved

Problem: Every uploaded file has different columns/types. Solution: MongoDB (flexible schema) + Pandas auto type detection + dynamic Pydantic models.
